# QStockPrediction

**Portfolio exposure meets volatility forecasting and experimental quantum estimation.**

QStockPrediction explores how asset simulation and forecast volatility feed into potential future exposure (PFE) for a multi-asset options portfolio. It combines a classical risk engine, variance-reduced sampling, a TensorFlow LSTM and exploratory quantum components in three inspectable Python modules.

## What is implemented

| Module | Role |
|---|---|
| [LastQModel.py](LastQModel.py) | Portfolio parsing, synthetic correlation assumptions, option payoffs, classical Monte Carlo, Latin hypercube and Sobol/antithetic sampling, and experimental amplitude estimation |
| [lstm_volatility_predictor.py](lstm_volatility_predictor.py) | Synthetic volatility generation, lookback features, Keras LSTM training and forecast visualization |
| [quantum_lstm_volatility_predictor.py](quantum_lstm_volatility_predictor.py) | Parameterized-circuit gate and recurrent-cell experiments for hybrid volatility prediction |

The main financial output is a quantile of **positive simulated portfolio value**. The engine also reports portfolio-value tail statistics. Those quantities should be interpreted using the payoff conventions in the source rather than assumed to be a complete counterparty-risk model.

## Start with the classical exposure engine

Create and activate a Python environment, then install the core numerical dependencies:

```bash
python -m pip install numpy scipy matplotlib
```

From the repository root, the following example uses the public class directly:

```python
from LastQModel import MultiAssetPFECalculator

portfolio = {
    "AAPL": {
        "spot": 150, "strike": 150, "volatility": 0.20,
        "maturity": 0.5, "option_type": "call",
        "position": 1, "notional": 100,
    },
    "MSFT": {
        "spot": 300, "strike": 300, "volatility": 0.25,
        "maturity": 0.5, "option_type": "put",
        "position": -1, "notional": 50,
    },
}

calculator = MultiAssetPFECalculator(confidence_level=0.95, use_quantum=False)
positions = calculator.parse_portfolio(portfolio)
result = calculator.classical_monte_carlo(positions, num_paths=10_000)
print(result["pfe"])
```

The scripts are imported from their filenames; this repository is not distributed as an installable `QStockPrediction` Python package.

## Forecasting and quantum experiments

The classical LSTM additionally needs TensorFlow and scikit-learn. Its data generator produces synthetic volatility sequences with simulated market events. The hybrid recurrent model and amplitude-estimation experiments need compatible Qiskit components; inspect their imports before creating a separate quantum environment.

The optional hardware adapter imports `azure_wrapper`, which is not included here. A hardware flag alone does not establish that an experiment ran on a physical device. Classical percentile fallbacks and simulated quantum results must be distinguished when comparing outputs.

## Research interpretation

Correlation is generated by explicit asset-class heuristics, rather than estimated from a market dataset. The calculations use simplified payoff and diffusion assumptions. Invalid correlation handling may fall back to uncorrelated paths with a warning, so inspect that diagnostic before interpreting a result.

The quantum routines are prototypes: state preparation, exposure discretization, oracle cost and equal-budget comparisons require further study before a practical advantage could be assessed. The repository does not establish out-of-sample trading performance or a calibrated production risk system.

For a complementary experiment with an interactive interface and separately recorded risk and oracle studies, see [Quantum Risk Observatory](https://github.com/FyodorAmanov1/quantum-estimation-lab).
